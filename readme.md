# Modernized HUD

This is a fork of the [Modernized Hud](https://www.nexusmods.com/morrowind/mods/54468) for OpenMW by [allardpong](https://www.nexusmods.com/morrowind/users/40698085). The mod was posted with entirely open permissions:

> hi, this was mostly a personal project I felt like sharing, and since I've stopped playing Morrowind I won't be working on this mod anymore, either I suggest looking for any alternatives, or if you're feeling brave, just fix my spagetti code and re-upload, the permissions are entirely open. 

## Changes

This fork includes changes to make it more compatible with [HUD Hider](https://www.nexusmods.com/morrowind/mods/59286). Now the HUD components will smoothly fade away as the HUD disappears.
